## Q2 persisted record (implemented): `TypedModule.release_plan: ReleasePlan` (ynz-typeck/src/release_plan.rs)
- `block_end: HashMap<(start,end) of Block.span, Vec<ReleaseEntry>>` (fallthrough end AND loop back-edge: same list)
- `return_edge: HashMap<(start,end) of Stmt::Return span OR the Ident span where auto-propagation fires, Vec<ReleaseEntry>>`
- `moved_at: HashMap<(start,end) of the argument Ident read, founder name>`
- `ReleaseEntry{name, binding:(name_span.start,end)=ScopeEntry.defined_at, ty, kind, fate}`; list is TOTAL (every binding leaving scope appears) and LIFO. `Fate`: Release | ReleaseIfLive | OmittedMoved | OmittedMaybeMoved(unused now) | OmittedReturned | OmittedNotOwner | OmittedUnsupportedType | OmittedReassigned.
- Producer: only typeck, at the points that already hold the facts: `record_block_exit` before each `scope.pop()` (check.rs:1140,3335,3475,3489,3577,3594,3660), `record_return_exit` (3764; wraps check_stmt_return 3822; and resolve_ident auto-propagation 4589), `check_transfer` consume site (moved_at), `finalize_release_plan` (3803, retroactive demotion of reassigned bindings). `Scope` gained `founder` (first entry of an alias class = sole release duty), `consumed_depth`, `founder_of`.
- Lookup: codegen reads `cg.typed.release_plan` by the AST node's own span (Block.span / Return span / Ident span) — no re-derivation of moves, ownership or aliasing in codegen. Precedents: `background_arg_sole_holder` (span-keyed), `LayoutDecisions` ((name, decl_span) salsa query).
- Total-list rule means a missing key is a compile-time ICE (prototype tolerates it only for generic fns, emit.rs emit_block_release) — never a silent leak.
- Key assumption (C4 uniquify): `emit_release_list` resolves slots by NAME in `cg.locals`; BindingKey is the unique part. It errors on two same-named entries in one list (sh1). After the uniquify pass the name lookup is exact; without it, outer shadowed owners (return lists span all frames) cannot be addressed. Matters in: emit_release_list slot lookup (15147), emit_null_founder_slot_on_move (15109, `cg.locals.get(founder)`), the crossing union (by name), `flush` position lookup `sm_crossing_names.position`.

## Task 3 conditional moves: null-slot-on-move is sufficient for single-pointer-slot heap types, with one amendment, and needs no separate flag.
- Run: c1 4/4, c2 5/5, c3 8/8 (arrays). Amendment: the move must null the FOUNDER's slot (the only releaser), not the named alias (c3: `eat(y)` nulls `x`); typeck records it at the consume site (`moved_at`, from `Scope::founder_of`). Aliases never release.
- Sufficient for: array, map, string-owner, channel, task handle, promoted maybe/union heap cells — any binding whose slot is one pointer where null means "no object" (not run beyond array).
- NOT sufficient as-is for inline aggregates: by-value shapes (frame-embedded `sm_crossing_shape_embed_set`), `maybe` envelopes `{flag,bits}`, `fixed<T>`, decimal cells (non-heap). They need whole-value zeroing at a move (`flag=0` is natural "none" for a maybe) or a per-binding flag. Also loop per-iteration `let` re-stores the slot, so no stale state.
- Cost vs Rust drop flags: Rust = 1 flag byte + store at move + test at exit only for conditionally-moved places (static elaboration). Here: 0 extra memory (slot reused), 1 null store at move sites, load+test+branch at exits only for `ReleaseIfLive` entries; definite moves are omitted statically (OmittedMoved). Same class; +1 frame store per move on the SM path.

## Task 5 typeck holes (in-plan blockers for C5; reproduce with spike-notes/probes/*.ynz, asan.sh, binary at 0280beb)
1. t3 move in loop — `while(..){ if(c){return}; eat(x) }`, x declared outside, `eat(give ..)`: typeck ACCEPTS (also on main, prints 3 three times). With the pass: iteration 2 passes a freed/nulled array: first build SEGV on freed memory (8228319), with null-on-move a null-deref panic (0280beb). Typeck must reject a transfer of an outer binding inside a loop body (or treat the back edge as a use of the moved class).
2. t6b field-assign sink — `let b: Bag = {items:[0]}; b.items = a; return b`: accepted; `a` is released at exit while the returned bag holds it; prints 0 instead of 3 (free-fill). `Stmt::FieldAssign` (and index set / `.add` / `.set` of heap values) are not in `check_transfer`'s closed sink list. They must consume or demote the stored root.
3. t7 multi-root Reaches — `let p: Pair = {first: a, second: c}; return p`: `binding_event_origin` (check.rs ~5467) joins only the FIRST root's alias class; returning p excludes a but releases c; prints `3 0` instead of `3 2`. Reaches must merge ALL roots' classes (union-find) so consume/return of any consumes all. (Single root t5 is safe: leak only.)
Also: reassignment from a non-fresh value (re1) and shadowing (sh1) need demotion/uniquify; strings are not releasable (S1); recursive element release for nested heap fields does not exist.
