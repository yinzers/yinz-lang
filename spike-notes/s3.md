## Findings so far (probes run on main build, /tmp/p/t*.ynz — sources reproduced in spike-notes/probes/)
- No break/continue: `continue`/`break` -> "`continue` is not defined" (t4). Stmt kinds: Expr, Let, Assign, If(no else), Match, While, For, Return, FieldAssign...
- t2: conditional move then later use -> rejected (typeck consume is flow-insensitive, permanent).
- t1: conditional move, no later use -> ACCEPTED. At function end binding is "consumed" but on the !c path it still owns -> static list can't free it (needs drop flag or leaks).
- t3 (HOLE): `while (...) { if (c) {return}; eat(x) ... }` with `eat(give rows)` and x declared OUTSIDE the loop is ACCEPTED -> loop-carried move. With a release pass (callee frees its give param) iteration 2 is UAF/double free. Typeck must reject (or demote) before the pass lands.
- t5/t6 (HOLE): `let b = { items: a }` (Reaches -> joins only FIRST root's class) and `b.items = a` (FieldAssign is not a transfer sink) are accepted; `return b` then releasing `a` at scope exit = UAF. Reaches must merge ALL roots' classes; storage sinks must be in the closed sink list or demote.
- Typeck `ScopeEntry.defined_at` = name span: usable BindingKey. TypedModule already carries span-keyed side tables (expr_types, background_arg_sole_holder) and a salsa-queried precedent (LayoutDecisions keyed (name, decl_span)).
- Runtime: SpawnStateFnFuture::drop (runtime.rs:1075) already walks per-frame BgArgDropEntry{byte_offset,kind,size} descriptors incl. BG_ARG_KIND_RELEASED rewrite = precedent for dynamic ownership flag per frame slot.
- Codegen exit emitters: plain ret sites emit.rs:4591/4600/4604 (fn end), 15459-15621 (lower_stmt_return); SM: 6273 (lower_sm_body end), 6296 (orphan), 15459 (SM return), 7332 (return of suspending call), 15887 (SM auto-propagate), wrappers 5368.. free_frame x10 (5496-5705) + 12456 (recursion child). Generic fns 1623 (third body path).
- lower_stmt_if/while/for/match are SHARED by SM (wait-free statements), while wait-bearing statements have SM copies: lower_sm_stmt_with_wait If 7223, While 7350, For->lower_sm_for 7565, Match->lower_sm_match 8152.
