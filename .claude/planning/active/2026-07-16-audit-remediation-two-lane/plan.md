## 3. Execution

### 3.1 Intent & End State  *(MANDATORY)*

**Purpose.** Ship the maximum confirmed-bug remediation *now* without corrupting two concurrently-executing
sessions (M7, M8) or a third (rules-corpus-cleanup). The organizing principle is **contention, not
severity**: a fix's lane is decided by which files it touches, never by how bad the bug is. A CRITICAL
bug whose fix touches `emit.rs` waits behind the gate; a LOW bug whose fix touches only `ynz-driver`
ships in Lane A today.

**Key outcomes (definition of done).**
- Every **CONFIRMED** finding across the five docs is fixed **with a test that reproduces the bug
  first** (RED→GREEN); every **THEORY-only** finding has a four-field deferral (WHAT/WHY/COST/TRIGGER)
  recorded in Future Requirements, never a blind fix.
- **No edit** to `emit.rs`, `state_machine.rs`, `golden.rs`, `pirates-roster/{entrypoint.ynz,expected_stdout.txt}`,
  or `primantis-orders/` galleries occurs before the gate phase confirms **both** M7 and M8 are done
  **AND merged** — their dirs physically in `.claude/planning/done/` AND their merge commits present on
  `main` (a `done/` dir alone is insufficient: `superseded`/`abandoned` also land in `done/` without
  the work ever merging — see Phase GATE).
- **Lane A exits clean against the other sessions:** `golden.rs` shows zero hash movement and
  `pirates-roster/entrypoint.ynz` still compiles byte-unchanged — proven by two blocking gates, so no
  Lane A landing can break M7 Phase 5.
- The **gate is check-once**: if M7/M8 are not both done AND merged (dir in `done/` AND merge commit on
  `main`), the plan HALTS at the gate with a status report — **no polling loop**.
- Each scratch doc whose findings fully close is **retired** into its permanent home (`IMP-*.md` /
  `.claude/graveyard.md` / `ADR-*.md` per [docs-checklist](../../../rules/docs-checklist.md)) and the
  scratch file deleted/trimmed. Numerics + non-concurrency docs retire in Lane A; memory-safety +
  codegen-miscompiles + typeck-soundness retire in Lane B (they carry Lane B findings).
- Two HIGH residuals (R1, R2) are surfaced with unsigned override blocks for the human gate — the plan
  does not self-sign.

**Disciplined-initiative guidance (when steps and reality diverge).**
- **The lane boundary is the invariant, not the phase list.** If any Lane A step is discovered to touch
  a contended file (e.g. a numerics fix unexpectedly moves a golden hash — R3), **STOP that step**, do
  not force it, and re-route the finding to Lane B via a FRAGO. The zero-golden-movement gate exists to
  catch exactly this; treat any movement as a lane-boundary breach, not a golden to regenerate.
- **The gate is a one-shot decision, not a wait.** At the gate phase: check once that both M7/M8 are done
  AND merged — dir in `done/` **and** merge commit on `main` (the dir alone can be `superseded`/
  `abandoned`, never merged). If either is not both, HALT and report — do not sleep, poll, or partially
  proceed. A blocked gate is a successful, expected outcome of this plan, not a failure.
- **Design silences are recon findings, not license to guess.** For M1's scope-exit drop-insertion pass
  and C1's union box ABI, the cited design docs are silent (¶1 assumptions). At Lane B start, re-read
  them against post-M7/M8 `main` and author the mechanism design explicitly (surface as
  `design doc X is silent on Y`), rather than inventing an unrecorded layout mid-codegen.
- **Sequencing inside Lane B is load-bearing:** M2 (heap-own conversions) **before** M1 (drop pass) so
  the drop pass is uniform; C1 (union box) **before/with** M1 so the drop pass frees boxed payloads —
  one golden-regen churn at the end, not several. F8's OOM-policy fix must leave M1's drop pass unable
  to free a *static* buffer.

### 3.2 Concept

Six Lane A phases (fork from `main`, ship independently) → **one HARD GATE phase** → five Lane B phases
(post-gate, contended files). Lane A closes its two zero-contention scratch docs and pays down every
non-codegen finding, ending with two blocking cross-session-safety gates. The gate phase is a one-shot
done-AND-merged check — both plan dirs in `done/` AND both merge commits present on `main` (not a
dir-only check: `superseded`/`abandoned` land in `done/` unmerged) — that either opens Lane B or HALTS
the plan with a report. Lane B lands the
codegen/runtime-ownership fixes in the audit-mandated order (M2→C1→M1), pays the gated demo/gallery debt
from decision D3, and retires the remaining three scratch docs.

- After Lane B, heap-owned locals are freed at every scope exit (block/loop/return) and across `wait`
  suspension points — no leak (RSS bounded on the repro), and **no double-free/UAF** (Miri/ASan/TSan

- A `number`/`int` literal assigned to a `float` binding is a compile error with a teaching diagnostic,

  bignum long-division sticky handoff) produces exact results verified by deterministic vectors. *(N1/N2/N4)*
- Deep parser nesting is rejected with a diagnostic at depth 256, never a stack abort. *(F2)*

- M1's drop pass emits calls to existing runtime drop glue — no new per-value overhead beyond the
